# PassCraft — Password Generator

A responsive password generator made with HTML, CSS and vanilla JavaScript.

## Features
- Generate passwords from 8 to 64 characters
- Choose uppercase, lowercase, numbers and symbols
- Uses the browser Web Crypto API for random selection
- Copy password to clipboard
- Simple password-strength estimate
- Responsive layout; no dependencies

## Run
Open `index.html` in a modern browser. Clipboard access works best on localhost or HTTPS.

## Concepts practised
DOM events, arrays, secure random selection with Web Crypto, input controls, clipboard API, and responsive CSS.

## Future improvements
